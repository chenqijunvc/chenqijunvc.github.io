    <p class="lead">The Pure Alpha framework addresses a fundamental question in investment management: how do you distinguish genuine manager skill from stylistic tailwinds?</p>

    <hr class="my-4">

    <h3>Core Idea</h3>
    <p>Most active manager evaluation frameworks confuse performance with skill. A manager may outperform because they have genuine insight — or simply because their style (value, growth, small-cap, etc.) happened to be in favor. The Pure Alpha framework separates these two sources of return through systematic holding-based analysis.</p>

    <p>By decomposing a manager's portfolio into its underlying factor exposures and comparing actual returns against the returns implied by those exposures, Pure Alpha isolates the component of return that comes from active decisions independent of style bias.</p>

    <hr class="my-4">

    <h3>Methodology</h3>
    <p>The framework operates in four steps:</p>
    <ol>
      <li><strong>Holdings-based factor decomposition</strong> — Map every position to its factor exposures</li>
      <li><strong>Return attribution</strong> — Calculate the return explained by factor exposures versus active bets</li>
      <li><strong>Consistency analysis</strong> — Evaluate whether active returns are persistent or episodic</li>
      <li><strong>Skill assessment</strong> — Distinguish genuine stock-picking skill from factor timing or style drift</li>
    </ol>

    <hr class="my-4">

    <h3>Applications</h3>
    <p>The Pure Alpha framework has applications for:</p>
    <ul>
      <li>Institutional consultant-grade manager due diligence</li>
      <li>Fund-of-funds manager selection and monitoring</li>
      <li>Internal assessment of active management programs</li>
      <li>Portfolio construction — identifying managers who provide genuine diversification through independent alpha sources</li>
    </ul>
