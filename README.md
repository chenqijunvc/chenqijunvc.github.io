# chenqijunvc.github.io

Personal website and research archive for **Vince (Qijun) Chen, CFA**, founder of [PortfolioFuture](https://portfoliofuture.com).

## Site structure

- `/` — current identity and PortfolioFuture
- `/about/` — founder story and professional background
- `/track-record/` — prior quantitative investment systems, research, and portfolio-management work
- `/writing/` — investment research and articles
- `/media/` — speaking, interviews, press, and recognition
- `/contact/` — direct contact links

`PortfolioFuture` in the primary navigation links to the company website and opens in a new tab.

## Publish on GitHub Pages

This repository is structured as a standard Jekyll site for the `chenqijunvc.github.io` user site.

1. Copy these files over the repository root.
2. Commit the changes.
3. Push to the branch configured for GitHub Pages (normally `main`).

If GitHub Pages is configured to **Deploy from a branch**, GitHub will build the Jekyll site automatically.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

## Content notes

- Historical investment-management pages are explicitly framed as prior work (2017–2026).
- PortfolioFuture is the current company and primary present-tense identity.
- AI / computer science is positioned as part of the technical toolkit rather than a separate personal brand.
- The source image for the PortfolioFuture feature is stored as optimized WebP assets under `img/`.
